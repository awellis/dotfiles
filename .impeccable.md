## Design Context

### Users
A single researcher uses this interface inside Emacs while reviewing timestamped Org notes. The main job is to reconstruct a train of thought over time, scan changes in emphasis, and move quickly between the timeline and the original note.

### Brand Personality
Thoughtful, scholarly, composed. The interface should feel like a carefully edited research notebook rather than a dashboard or developer tool.

### Aesthetic Direction
Flagship-quality editorial research notebook. It should use the editor’s FiraCode Nerd Font throughout and borrow AUCTeX’s typographic language: scaled, coloured structural headings; fixed-pitch prose; restrained syntax-like emphasis; and quiet secondary metadata. It should work with the existing Catppuccin theme, with chronological rhythm, generous but efficient spacing, and colour used chiefly to encode note type. Avoid card grids, decorative gradients, pill badges, and generic dashboard styling.

### Design Principles
- Put the thought first: note prose has priority over controls and metadata.
- Make chronology visible through rhythm, date sections, and a quiet timeline motif.
- Separate editorial prose from functional metadata through AUCTeX-like weight, scale, and colour rather than changing font family or adding containers.
- Use theme-derived colours and redundant text labels so type never depends on colour alone.
- Keep advanced controls available but visually quiet; preserve keyboard-first operation.
